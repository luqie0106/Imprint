# Non-Local / WGIF 去朦胧实验

默认关闭。在去朦胧页的“实验去朦胧”中选择“关闭 / 保守 / 强”。选择保守或强会开启当前照片的自动处理；关闭自动处理也会关闭实验模式。切换后自动刷新预览，导出使用同一选择，无需修改环境变量或重启后端。

模式按照片保存在 Imprint XMP 设置中，重新载入时还原。预览缓存包含模式；批处理开始时固定每张照片的选择，之后的界面修改只影响后续任务。旧导出文件的像素不会随开关改变。

桌面/API 请求中的 `nonlocal_mode`（`off / conservative / strong`）优先于环境变量。旧的直接 Python 调用未传模式时，仍可使用 `IMPRINT_NONLOCAL_RELIEF`：

- 未设置或 `off`：现有物理去朦胧。
- `1`：上一轮的保守版本，仅减轻可靠近景的减光。
- `strong`：Non-Local 雾线透射率、可靠度加权 WLS 和 WGIF 精修。

实验仅用于自动空间模式。低可信度大气光、大气光亮度低于估计门槛、明显太阳剪裁和求解失败时使用原路径。预览显示实际启用状态或回退原因；选择“强”不表示本张照片一定使用了实验估计。状态来自本次渲染，并与预览一起缓存。强版本要求大气光线性亮度至少为 0.20，保守版本为 0.12。这个门槛是实验估计的适用条件，不能据此判断拍摄现场光线不足；旧版本在海上风机实图中损失了水面纹理，因此保留该门槛。

强版本先在低分辨率线性 RGB 上按大气光方向聚类，以径向范围估计透射率，使用样本数量和范围作为可靠度。单纯的半径比把每条雾线的最远端视为无雾；整个远景仍有雾时，这会高估透射率。现在使用 WGIF 去雾应用中的暗通道先验（15×15 窗口，omega=31/32），从雾线末端重复样本校准绝对尺度，并施加 Non-Local 论文的非负辐射下界。

WLS 保留原透射率先验，WGIF 精修光学厚度：3×3 方差用于边缘权重，epsilon 随引导图动态范围变化，权重经高斯平滑；回归矩与系数平均使用相同窗口半径。最后投影到整幅图共享的连续 RGB 映射，再检查逐像素的辐射下界：同一 RGB 不会因靠近建筑或处理块边缘而接受不同变换。这会牺牲部分位置相关的深度恢复，是避免天空明暗带的约束。

可靠估计成功时，强版本减少自然感和暗部减光限制；亮度和暗部保护的最大值仍保持最大保护。颜色沿原图色相方向变化，关闭额外的颜色恢复，保留现有高光肩部和源颜色上限。CPU 和原生 GPU 使用相同透射率与有效参数；没有新增 GPU 算法或依赖。

公式参考：

- Berman et al., [Non-Local Image Dehazing, CVPR 2016](https://openaccess.thecvf.com/content_cvpr_2016/html/Berman_Non-Local_Image_Dehazing_CVPR_2016_paper.html)，[作者代码](https://github.com/danaberman/non-local-dehazing)。
- Li et al., [Weighted Guided Image Filtering, TIP 2015](https://pubmed.ncbi.nlm.nih.gov/25415986/)，[公开实现](https://github.com/Luxiush/Weighted-Guided-Image-Filter)。

这是结合雾线和暗通道先验的独立实验实现，没有复制上游代码、颜色后处理或输出格式；不是原论文完整算法的复现。暗通道的黑色反射率假设也可能失效，因此不取消夜景、太阳和不可靠估计的回退。开关启用不代表所有场景都已满足摄影质量要求，实际效果应对照相同 RAW、参数和全分辨率输出。
