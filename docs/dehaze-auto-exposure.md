# 自动曝光

去朦胧页提供独立的逐图“自动曝光”开关，默认关闭。它在线性 RGB 中用同一个倍率提高整张照片的曝光，不自动调整高光、阴影、白色、黑色或手动曝光滑块。开启后显示本次预览实际增加的 EV。

处理位于去朦胧之前。用最长边不超过 768 像素的分析图计算亮度中位数，以 0.18 为目标；只提亮，最多增加 2 EV。倍率同时受输入图像最亮通道限制，预留到 0.95 的余量。已有满值高光时不增加曝光，并显示高光余量不足。这里的高光限制只约束自动曝光这一步，后续镜头暗角校正、手动调整及去朦胧仍会改变像素。提亮后的像素也参与大气光估计，实验去朦胧可能从回退变为实际启用；界面分别显示曝光增益与实验状态。

这是一种曝光起点，不根据 EXIF 曝光补偿机械地反向加 EV，也不代表自动测光的唯一正确结果。黑色画面不提亮；本来已经达到目标亮度的画面保持 0 EV。严格的最亮通道限制也可能被灯光或亮点约束，不会用局部压高光来换取更大的曝光增益。

预览、全尺寸预览与导出使用相同的计算和处理步骤。低分辨率预览依据预览解码的像素估计；最终导出重新读取全尺寸照片，细小高光及 RAW 解码差异可能使最终曝光更保守。L0/L1/L2 在同一解码尺寸下使用同一次曝光估计。

选择保存在 Imprint 自定义 XMP 设置中；批处理开始时固定每张照片的选择。自动曝光随去朦胧导出写入 DNG 的增强像素，后续仍可在 ACR 中调整曝光和影调。理光风格的独立导出不执行这个去朦胧处理阶段。Imprint 自定义开关不是 Adobe 原生自动曝光指令，XMP 兼容曲线也不能保证与 ACR 的渲染相同。

原始照片和原始预览保持不变。已有导出文件不会自动更新，需重新导出才能得到新的像素。
