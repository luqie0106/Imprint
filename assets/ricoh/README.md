# Ricoh 风格素材

这里集中存放协作者提供的四套原始素材，保留各自的目录、说明和生成脚本：

- `Ricoh_GR2_CameraRaw_Presets/Presets/`：GR2 的 4 个 Camera Raw XMP 预设。
- `Ricoh_GR3_CameraRaw_Presets/Presets/`：GR3 的 6 个 Camera Raw XMP 预设。
- `Ricoh_GR2_PS_Filter/`、`Ricoh_GR3_PS_Filter/`：Photoshop JSX、LUT 等原始参考素材。

Imprint 当前的“理光风格”页面读取前两组 XMP 预设，为所选照片创建同名 XMP 伴生文件。已有伴生文件不会覆盖，原照片不会被更改。Photoshop 的 JSX 和 LUT 保存在这里供后续功能使用；当前页面不会执行这些脚本或 LUT，也不会在应用内渲染 Camera Raw 效果。

这几套风格是仿理光色彩的独立创作，不是理光官方相机配置文件。
