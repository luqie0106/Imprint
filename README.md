# Photo Sort (RAW 连拍优选与个人审美引擎)

本工具专为摄影师（特别是航空、体育摄影等高频连拍场景）设计，用于全自动筛选和淘汰冗余的连拍照片，支持各类主流相机的 RAW 格式（`.NEF`, `.ARW`, `.CR3`, `.RAF` 等）。

经过底层架构全面重构，当前版本不仅具备极速稳定的聚类性能，还融入了顶尖的多维综合人工智能评估系统。

---

## ✨ 核心特性

### 1. 智能连拍聚类引擎 (Burst Grouping)
- **感知哈希 (dHash) 视觉比对**：彻底摒弃传统直方图对比，利用差异哈希算计图像结构特征（汉明距离），无视曝光微变和白平衡跳动，精准识别同一场景。
- **亚秒级 (Sub-second) EXIF 解析**：深度挖掘 RAW 内嵌元数据，支持毫秒级时间戳分割，完美驾驭现代微单 30fps 以上的极限连拍。
- **平移跟拍 (Panning) 智能截断**：采用“首帧锚点比对”逻辑。当你追随飞机或赛车长跨度连拍时，一旦角度构图发生实质性改变，程序将自动为你断开并开启新的子组，**确保每个经典角度都能为你保留最优的 1~3 张**。

### 2. 多维综合打分引擎 (Scoring Engine)
抛弃单一死板的评估，采用多维度加权公式，确保选出的照片不仅焦点实，而且构图美、曝光准。
- **60% | AI 美感与构图 (CLIP)**：内嵌基于 OpenAI CLIP 视觉主干的自研多层感知机（MLP），你的个人审美偏好将被量化为高维向量，精准捕捉“照片是否有高级感”。
- **30% | 人脸优先锐度 (Sharpness)**：内置 Haar Cascade 人脸检测。只要画面中有人脸，锐度评估将仅针对人脸区域进行（完美解决“背景树叶锐利但人脸虚化”的痛点）。若无人脸（如拍风景），自动降级为画面中心区域测算，并在组内进行 Min-Max 归一化。
- **10% | 宽容欠曝的曝光评分 (Exposure)**：深度分析直方图数据。由于摄影师常采用“宁欠勿曝”策略，系统会对“高光死白”予以重惩，而对“暗部死黑”仅做轻微扣分处理。

### 3. 轻量化与便携分发 (Zero-Dependency)
- **双引擎自动切换**：在本地开发与训练时使用 `PyTorch` 和 `Transformers`；但在最终分发的应用程序中，模型会被完全熔合为单体 `.onnx`，由极速轻量的 `onnxruntime` 驱动，**安装包体积锐减数个 GB**！
- **GitHub Actions 云端打包**：提交代码并打上 Tag，微软云端流水线将自动为你输出绿色免安装的 macOS `.dmg` 与 Windows `.zip` 应用程序包。

## 🚀 安装与运行

### 方式一：直接下载免安装版（推荐给所有用户）
无需配置任何编程环境，直接进入本项目的 [**Releases**](https://github.com/luqie0106/photo_sort/releases) 页面，下载最新的安装包。
双击启动，在图形化界面 (GUI) 中选择照片文件夹，点击运行即可。

### 方式二：通过源码运行（推荐给极客与开发者）
如果你希望自己修改代码或微调模型，请使用 Conda 环境：

```bash
# 1. 准备环境 (推荐 Python 3.11)
conda create -n photo_sort python=3.11
conda activate photo_sort

# 2. 安装运行环境依赖
pip install -r requirements.txt

# 3. 启动图形化主程序
python main.py

# (可选) 纯命令行批量无头运行
python main.py --cli
```

## 🧠 训练属于你的专属审美模型

项目随附了图形化微调工具，你可以把这套 AI 调教成世界上最懂你审美的专属助理：

1. 准备数据：创建两个文件夹，分别放入你精心挑选的 RAW 预览图（`like`）和落选的废片（`dislike`）。
2. 打开训练器：运行 `python src/trainer_gui.py`，导入目录并点击训练。
3. 熔合模型：训练完成后，运行我们在 `scripts/` 下提供的导出脚本：
   ```bash
   python scripts/export_onnx.py
   ```
   它会自动将庞大的 CLIP 特征提取器与你刚训练好的轻量权重，熔铸成一个极速的 `photo_sort_model.onnx`。
4. 打包发布：直接提交代码到 GitHub，流水线会自动为你生成内置了你专属审美的全新免安装程序包！
