# Photo Sort (RAW 连拍优选与个人审美引擎)

本工具专为摄影师（特别是航空、体育、人像、生态等高频连拍场景）设计，用于全自动筛选和淘汰冗余的连拍照片，支持主流相机的各类 RAW 格式（`.NEF`, `.ARW`, `.CR3`, `.RAF` 等）。

软件集成了 **RAW 智能连拍优选**、**个人审美偏好训练** 与 **模型本地化管理** 于一体，提供现代化的图形交互界面。

---

## ✨ 核心特性

### 1. 现代化一体集成界面 (Unified App)
- **多标签快速切换**：启动主程序后即可自由切换【📷 连拍优选】、【🧠 偏好训练】与【📦 模型管理】。
- **模型状态动态感知**：自动识别本地 ONNX 极速引擎、PyTorch 引擎或纯 OpenCV 模式，状态实时响应。
- **全自动闭环工作流**：在图形界面完成个人审美训练后，**自动熔铸为 ONNX 极速模型**，免去任何额外脚本操作。

### 2. 模型本地管理与自动下载 (Model Manager)
- **自动检测与下载**：启动或运行时自动检测 CLIP 基础模型，缺失时一键下载至当前目录下的 `./models/` 文件夹中。
- **网络加速支持**：内置国内加速镜像源（`hf-mirror.com`），支持实时下载进度与速率显示。
- **完全离线便携**：所有模型文件均存放在程序目录下，随时可随项目整体迁移或离线使用。

### 3. 智能连拍聚类引擎 (Burst Grouping)
- **感知哈希 (dHash) 视觉比对**：利用差异哈希算计图像结构特征（汉明距离），无视曝光微变和白平衡跳动，精准识别同一场景。
- **亚秒级 (Sub-second) EXIF 解析**：深度挖掘 RAW 内嵌元数据，支持毫秒级时间戳分割，完美驾驭现代微单 30fps 以上的极限连拍。
- **平移跟拍 (Panning) 智能截断**：采用“首帧锚点比对”逻辑。当你追随飞机或赛车长跨度连拍时，一旦角度构图发生实质性改变，程序将自动断开并开启新的子组，**确保每个经典角度都能为你保留最优的 1~3 张**。

### 4. 多维综合打分引擎 (Scoring Engine)
- **60% | AI 美感与构图 (CLIP + MLP)**：内嵌基于 OpenAI CLIP 视觉主干与自研 MLP 分类头，精准量化你的摄影偏好。
- **30% | 人脸优先锐度 (Sharpness)**：内置 Haar Cascade 人脸检测。画面有人脸时仅对人脸区域测算焦点清晰度；无人脸时自动降级为画面中心区域测算，并在组内进行 Min-Max 归一化。
- **10% | 宽容欠曝的曝光评分 (Exposure)**：深度分析直方图数据，对“高光死白”予以重惩，对“暗部死黑”轻微扣分。

## 🚀 安装与运行

### 运行环境要求（Conda py311）
```bash
# 激活 Conda 环境
conda activate py311

# 安装依赖
pip install -r requirements.txt
```

### 启动方式

#### 1. 启动一体化图形主程序（推荐）
```bash
python main.py
```
启动后可在界面中选择：
- **连拍优选**：选择照片文件夹，一键分析连拍组并自动将淘汰片移至审查子目录。
- **偏好训练**：指定包含 `like`（喜欢的片）与 `dislike`（淘汰的片）的文件夹，点击开始训练，训练完成后自动生成 `photo_sort_model.onnx`。
- **模型管理**：查看模型状态，一键下载基础视觉主干至本地 `./models/` 目录。

#### 2. 命令行快捷指令
```bash
# 纯命令行无头运行连拍筛选
python main.py --cli

# 命令行一键下载基础模型到本地 models/ 目录
python main.py --download-models

# 命令行从现有权重手动熔铸 ONNX 模型
python main.py --export-onnx
```

## 🧠 如何训练专属审美模型

1. **准备样本数据**：准备一个数据集根目录，内部建立两个子文件夹：
   - `like/`：放入你精心挑选满意的 RAW 照片。
   - `dislike/`：放入你淘汰不喜欢的 RAW 废片。
2. **在软件中训练**：打开软件，切换到 **🧠 偏好训练** 标签，选择该数据集目录，点击 **▶ 开始训练与熔铸**。
3. **即刻生效**：训练完成后，程序会自动生成 `photo_sort_model.onnx`，连拍筛选将立即启用最新的个人审美偏好进行极速智能打分！
